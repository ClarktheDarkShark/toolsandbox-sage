# Final Limitations And Future Work

## Limitations

- The frozen best3 portfolio is the broad locked claim portfolio; V2.6 expanded contact-scalar helpers are a candidate portfolio with strong secondary evidence.
- The V2.6 matched gap-enriched frozen250 run proves a `17.39%` relative helper-fit gap reduction on a targeted manifest, not the original formal250 absolute `44.4% -> <=40.0%` threshold.
- The V2.6 original formal250 expanded run reduced feedback no-current-helper-fit from `52.0%` to `46.0%`, but this feedback-derived reference differs from the earlier static `44.4%` figure.
- The V2.6 expanded 500 run was scale-positive, but its broad helper-fit reduction was `7.10%`, below the 10% relative gap-reduction target because many remaining no-fit cases are safe-insufficient-information or unclassified lanes outside contact-scalar coverage.
- The expanded 500 comparison uses preserved best3 500 evidence rather than a current-code matched best3 rerun; stochastic-run variance should be acknowledged.
- `plan_contact_search_from_scalar_constraint` improved after routing repair but still has visible-not-called exposure; it should remain under routing watch before any broader promotion claim.
- A 1032 expanded run was deferred because the 500 result already tests broad non-external scale and a full 1032 expanded run would add substantial live-candidate cost over sparse/external lanes not targeted by contact-scalar helpers.
- Outcome/task-completion remains primary. Canonical/reference score is secondary and can diverge when helper substitution or route mismatch occurs.

## Future Work

- Run a current-code best3 500 rerun if an exact same-code, same-manifest comparison is needed for publication-grade V2.6 expanded claims.
- Run expanded 1032 only if the research narrative requires broad full-benchmark validation beyond non-external 500 evidence.
- Mine remaining safe-insufficient-information and unclassified no-fit lanes; the current expanded contact-scalar pack does not address them.
- Continue improving evidence-aware routing to reduce visible-not-called exposure without suppressing high-value helpers on matching tasks.
- Extend feedback packets to distinguish static no-current-helper-fit from dynamic helper-visible-but-not-called adoption gaps.
