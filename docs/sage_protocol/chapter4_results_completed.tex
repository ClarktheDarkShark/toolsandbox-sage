\section{Evaluation Contract}
\label{sec:chapter4-evaluation-contract}

Outcome/task-completion similarity is the sole publication performance
endpoint. The same frozen evaluator must produce an outcome for every benchmark
task in every arm. Tool-route similarity and mechanism counts may be reported
as diagnostics, but they cannot determine a performance result or hypothesis
decision.

Each publication comparison runs its fresh non-learning control and SAGE arm
concurrently in isolated child processes. Online SAGE receives only the
same-run control row for the matching task boundary. Stored task results and
stored model responses are not replayed. Every live pair exposes a verified
Task Compare dashboard in the external browser before its first model request.

A validated generated tool may be the terminal action when it safely achieves
the requested final state. No separate visible native-tool call is required.
Final-state correctness, minefield protection, allow-list enforcement, runtime
safety, and correct abstention remain required.
