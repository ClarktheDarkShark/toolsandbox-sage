The formal repair validation used:

- generation off;
- candidate/SAGE task cache off;
- OpenAI response cache disabled;
- routing evidence disabled;
- diagnostic force-call env vars absent;
- no low-quality cohort override;
- no code or registry changes between matched arms.

No experimental actor/router bridge policy, final-answer retention policy,
scrambled tool-name compatibility runtime change, side-effect checker change,
scoring change, or dashboard/export-only change was imported to make the result
work.

The one helper that appeared to require runtime bridge behavior,
`plan_contact_relationship_batch_update`, was retired for registry-only review.
That is why the passing result should be described as a repaired registry-only
Praxis candidate, not as the original frozen experimental BridgePack.
